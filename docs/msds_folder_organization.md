# MSDS Folder Organization Rule

이 문서는 MSDS 샘플 폴더를 어떻게 나눌지 정한다.

## 기본 원칙

- **폴더는 물질 단위로 꼭 나누지 않는다.**
- **같은 CAS No.의 HTML/TXT/PDF는 같은 폴더에 둔다.**
- **서로 다른 물질도 같은 배치 폴더에 함께 둘 수 있다.**
- 폴더를 나누는 기준은 물질이 아니라 **검증 목적**이다.

## 권장 구조

### 1. 공통 배치 폴더

여러 물질을 한 번에 검증할 때 사용한다.

- `samples/msds_batch/`

### 2. 전용 실험 폴더

특정 물질군만 따로 검증하고 싶을 때 사용한다.

- `samples/msds_bromotoluene_batch/`

## 언제 새 폴더를 만드는가

- 같은 물질이 아니라 다른 문서군을 따로 비교할 때
- 파서 수정 전후를 분리해서 보고 싶을 때
- 특정 실험만 격리해서 재현하고 싶을 때

## 언제 새 폴더를 만들지 않는가

- CAS No.가 같은 파일을 더 넣는 경우
- HTML, TXT, PDF 같은 포맷만 늘어나는 경우
- 단순히 샘플 파일이 몇 개 추가되는 경우

## 운영 권장

1. 일반적인 샘플은 `samples/msds_batch/`에 모은다.
2. 특별한 비교 실험이 있을 때만 별도 폴더를 만든다.
3. 폴더 이름은 물질명보다 검증 목적이 드러나게 붙인다.
